# dify-plugin-dav

Consolidated DAV plugin for Dify: CalDAV calendar/task tools, CardDAV contact tools
(one tool provider `dav` with independent `caldav_*`/`carddav_*` credentials) and a
WebDAV online-drive datasource (provider `webdav`).

Package ID: `shaba/dav`. Replaces `shaba/caldav`, `shaba/carddav`, `shaba/webdav`.

Status: pre-alpha. Sources baselines (see /home/shaba/projects/dify/2026-11-10-dify-plugin-consolidation.md):
- dify-plugin-caldav 1b45a87b (v0.0.1)
- dify-plugin-carddav 3275a364 (v0.0.1)
- dify-datasource-webdav 897ef488 (v0.0.1)
